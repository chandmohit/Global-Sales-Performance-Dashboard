# Global Sales Performance Dashboard (Power BI)

## Project Overview
This project analyzes global sales performance using Power BI. The dashboard provides insights into sales, profit, product performance, and regional trends to help understand business performance and identify areas for improvement.

## Dataset
The dataset contains sales transaction data with information about:
- Sales
- Profit
- Products
- Countries/Regions
- Customer segments
- Order dates
- Quantity sold

## Business Questions
- What are the overall sales and profit performance?
- Which countries or regions generate the highest sales?
- Which products contribute the most revenue?
- What are the monthly sales trends?
- Which areas have high sales but lower profitability?

## Dashboard Features
- KPI cards for Sales, Profit, and Quantity
- Sales performance analysis by region
- Product category analysis
- Time-based sales trends
- Interactive filters and slicers
- Data visualization using Power BI

## Key Insights
- Identified top-performing regions based on sales and profit.
- Analyzed product categories contributing to business growth.
- Compared sales trends over time to understand performance patterns.
- Highlighted areas where profitability can be improved.

## Tools Used
- Power BI
- DAX
- Data Visualization
- Excel
